# 快捷键 PDF 速查指南

用户提供主题、操作清单或快捷键后，将其整理成便于按动作查找的单页指南。默认沿用本项目已确认的最终版式；用户本次要求优先。

## 内容与准确性

- 按使用意图分类，每项先说明“想做什么”，再提供按键。默认约 30 项、六类；根据主题调整，不凑数。
- 核对当前软件版本、操作系统和实际绑定。能读取本机配置时优先查配置与运行时；不能验证时使用官方文档并注明适用环境，不冒称本机已核对。
- 区分模式和上下文，例如 Evil 普通模式、标题行、列表项、表格内。同一按键对应多个动作时，在分类提示或动作说明里标明条件。
- 合并成对动作时，说明与按键顺序必须对应，例如“删除 / 插入行”对应“删除键 / 插入键”。
- 缩短动作描述，保留意图和必要条件。需要长解释的内容放页脚，不把整句教程放入快捷键列。
- 附简短按键图例，解释本主题涉及的 Ctrl、Meta、Shift、回车、空格和连续按键。macOS Option 是否作为 Meta 需核实。
- 不因制作指南而修改软件配置、用户笔记或添加快捷键。Emacs 求值使用 emacsclient，保留共享会话。

## 已确认的版式规则

- 默认 A4 横向、单页，主体为**两栏，每栏纵向放三个分类**；按左栏从上到下、再右栏从上到下阅读。
- **每项只占一行：动作说明左对齐，快捷键在同一基线上、靠分类右边界统一右对齐。** 不使用快捷键在上、说明在下的布局。
- 动作文字使用深灰色；快捷键使用醒目的蓝色并加粗。所有分类使用同一种低调的青绿色。
- 白底、细分隔线、适度留白；不使用大面积彩色卡片、圆角色块或装饰编号。
- 同一栏的说明起点与快捷键右边界保持一致。以字体实际宽度测量文本，左右内容之间至少留 12pt；不允许重叠、截断或自动换为两行。
- 正文和快捷键不小于 10pt，分类标题约 13pt，主标题约 22pt。快捷键用等宽字体；中文字体必须嵌入 PDF，保持文字可搜索、复制。
- 推荐几何参数：页边距 28pt、两栏间隔 28pt、列表行距至少 14pt。分类高度按条目数计算，并在分类之间留明确间隔。
- 推荐颜色：动作 #27323D，快捷键 #155BC4，分类 #247A78，辅助说明 #68747F，分隔线 #DCE1E5。
- 每类标题下可放一行灰色上下文提示。页脚放按键图例及一至两个真正有用的易错示例。
- 默认先精简低频条目或冗长文案来满足单页要求，不缩小文字硬塞。用户明确需要更多内容时，才协商更多页面或更大纸张。

## 生成与验收

- 使用可用的 PDF 制作 skill 和运行时；推荐 ReportLab 排版，Poppler 渲染 PNG。创建前遵守当前环境的产物操作标记要求。
- 字体路径在当前机器查找，不将另一台机器的绝对路径写死；可用时采用 Maple Mono NF CN 或其他支持中文及按键符号的字体。
- 成品放在当前任务产物目录，默认不要写入本配置仓库。稳定命名为主题对应的 PDF、PNG；修改时同步更新二者。
- PDF 是文字和矢量排版，不将整张图片嵌入 PDF 代替文字。PNG 必须由最终 PDF 渲染，长边至少 2800 像素。
- 检查 PDF 只有一页、A4 横向、中文文字可提取；对每一行检查说明宽度 + 快捷键宽度 + 间距不超过栏宽。
- 打开最终 PNG 目视检查：单行左右对齐、蓝色按键突出、分类清楚、无重叠溢出乱码，整页及实际尺寸均可读。出现问题先修正再交付。
- 简短交付 PDF 与图片预览，说明本次变更；不声称未经验证的绑定或环境已核实。
